Горячие кнопки

← / →
предыдущий / следующий кадр
Space + перетаскивание
перемещать увеличенное изображение
R
отметить кадр проверенным
Shift+R
снять проверку и перейти к другому кадру
S
пропустить кадр
E
переключить режим просмотра / редактирования
A
добавить фигуру типа выбранной; без выбора — bbox
W
включить инструмент «Добавить полигон»
M
назначить категорию кадру
Backspace / Delete
удалить выбранный bbox / полигон
Alt/Ctrl + клик
по вершине — удалить точку; по ребру — вставить новую, в том числе во время рисования
Enter
завершить рисуемый полигон (инструмент «Добавить полигон»)
1–2 (Detect)
класс выбранного или следующего bbox — train / number
1–5 (Seg)
класс рисуемой, выбранной или следующей маски — body / autocoupler / axlebox / bogie / hose
Esc
отменить текущий инструмент
Ctrl+V
вставить изображение из буфера
Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z
отменить / повторить действие

# AI Train

Веб-приложение на FastAPI для разметки изображений, экспорта YOLO-датасетов,
запуска моделей детекции/сегментации и анализа фото или видео с поездами.

В одном интерфейсе доступны два режима:

- **Разметка** — подготовка аннотаций, проверка моделей и экспорт YOLO;
- **Анализ** — обработка фото и видео, распознавание номеров, объединение
  фрагментов и просмотр результатов на схеме локомотива.

## Запуск сайта

```powershell
python -m pip install -r requirements.txt
python -m uvicorn server:app --reload --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/`.

Локальные загрузки, результаты анализа и база SQLite сохраняются в
`analysis_data/`. Эта папка исключена из Git.

## Структура проекта

```text
analysis/                   серверная часть режима анализа
frontend/                   единый интерфейс разметки и анализа
tests/                      автоматические тесты
tools/detect/               обучение модели детекции
tools/segmentation/         обучение модели сегментации
tools/auto_segment_sam2.py  автоматическая разметка через SAM 2
server.py                   FastAPI-приложение и API разметки
```

## Экспорт готового датасета

В экспорте YOLO сайт сразу создаёт:

```text
data.yaml
classes.txt
images/
  train/
  val/
labels/
  train/
  val/
```

В окне экспорта можно:

- включить «Не разбивать файлы на папки категорий» и получить плоские `train/val`;
- задать начальный номер общей нумерации;
- указать долю `validation` (по умолчанию 20%);
- включить пустые YOLO-аннотации для negative samples.

Папка `test` не создаётся и для обучения не используется. `data.yaml` содержит переносимые относительные пути, поэтому структуру после распаковки менять не нужно.

## Датасеты и обучение

Канонические папки:

```text
dataset/
  detection/
  segmentation/
```

Полный архив проекта можно распаковать прямо в корень `dataset/`, как он скачан с сайта:

```text
dataset/
  data.detect.yaml
  data.segment.yaml
  images/
  labels/
  project.json
```

Скрипт сам выберет YAML нужной задачи и подготовит внутри игнорируемой папки `dataset/.prepared/` совместимое с YOLO представление. Исходные файлы не перемещаются и не дублируются, если файловая система поддерживает жёсткие ссылки. Папка `test` не создаётся.

Можно распаковать содержимое ZIP с сайта прямо в соответствующую папку и запустить:

```powershell
python tools/detect/train.py
python tools/segmentation/train.py
```

Ещё короче — передать скачанный ZIP напрямую; скрипт безопасно распакует его в `dataset/<задача>/imports/`:

```powershell
python tools/detect/train.py --data "C:\Downloads\yolo_detect.zip"
python tools/segmentation/train.py --data "C:\Downloads\yolo_segment.zip"
```

`--data` также принимает папку или конкретный YAML. Полезные параметры обоих скриптов: `--model`, `--name`, `--epochs`, `--batch`, `--imgsz`, `--device`, `--workers`, `--cache`. Полный список: `python tools/detect/train.py --help`.

Без `--data` сначала ищется YAML внутри папки соответствующей задачи, затем — подходящий `data.detect.yaml`, `data.segment.yaml` или `data.yaml` во всём `dataset/`. Старый экспорт с `path: .` автоматически получает локальный переносимый `data.local.yaml`.

## Результаты и модели сайта

Новые запуски сохраняются структурированно:

```text
runs/
  detect/
    ГГГГММДД_ЧЧММСС_имя/
  segment/
    ГГГГММДД_ЧЧММСС_имя/
```

Перед каждым распознаванием сайт ищет самый свежий `weights/best.pt` по времени изменения. Если во время работы сайта завершилось новое обучение, следующая обработка автоматически загрузит новую модель; перезапуск сервера не нужен. Старый путь `runs/segmentation` всё ещё читается для совместимости.

Явно зафиксировать модель можно переменными окружения:

- `AI_TRAIN_MODEL_PATH` — детекция;
- `AI_TRAIN_SEG_MODEL_PATH` — сегментация.

Сегментация на сайте выполняется в обучавшем разрешении `1280` и с порогом
`0.39`, выбранным по максимуму Mask F1 последней модели. При необходимости их
можно переопределить через `AI_TRAIN_SEG_IMGSZ` и `AI_TRAIN_SEG_CONF`.

## Автоматическая разметка через SAM 2

`tools/auto_segment_sam2.py` находит объекты YOLO-детектором и строит для них
точные PNG-маски с помощью локальной установки SAM 2. Исходные изображения не
изменяются.

Укажите папку с SAM 2 через переменную окружения (без неё используется
`~/Desktop/sam2`) и запустите инструмент отдельным окружением:

```powershell
$env:AI_TRAIN_SAM2_ROOT = "C:\путь\к\sam2"
.venv-sam\Scripts\python.exe tools\auto_segment_sam2.py "C:\путь\к\фото" `
  --recursive --classes body
```

Путь к checkpoint можно переопределить через `AI_TRAIN_SAM2_CHECKPOINT` или
параметр `--sam2-checkpoint`. По умолчанию результаты сохраняются в
`runs/sam2_auto_masks/`: общие и отдельные маски, контрольные наложения,
метаданные JSON и итоговый `summary.json`. Папка `runs/` исключена из Git.

Локальные датасеты, веса и результаты запусков не добавляются в Git.
